# Movie Recommendation System

This is a Python project that recommends movies based on genre similarity.

## How it works
- Each movie can have multiple genres
- The system compares genres between movies
- Recommendations are based on the number of common genres

## Features
- Multi-genre support
- Similarity based on genre overlap
- Top 5 recommendations

## Technologies Used
- Python
- Pandas

## Example
Input: Avengers  
Output:
Iron Man  
Captain America  
Spider-Man  
Thor
